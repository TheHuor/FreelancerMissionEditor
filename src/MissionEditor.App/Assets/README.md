# Mission Editor assets

Created with the built-in Image Gen tool for this editor, 2026-10-31.

- MissionEditor.png: transparent application icon; source for title bar and Windows icon.
- MissionEditor.ico: 16, 24, 32, 48, 64, 128 and 256 px PNG frames, resized with System.Drawing and packed as ICO.
- GraphBackground.png: deliberately low-contrast starfield and nebula; displayed at 55% opacity behind graph content.

## Icon prompt

Create a single professional Windows desktop application icon for a Freelancer-inspired space mission editor. Transparent background. Centered compact readable symbol: a strong angular ice-blue navigation chevron integrated with three connected mission graph nodes on a partial orbital arc. Deep navy inner body, cyan illuminated edges, tiny warm amber waypoint accent. Flat polished restrained sci-fi instrument design with minimal metallic depth, crisp silhouette, strong legibility at 32x32. Square 1024x1024 composition with safe margins, symbol fills 80 percent of canvas. No text, lettering, words, logos, background scene, stars, app mockup, drop shadow outside icon, or complex tiny details. Original identity for a mission scripting tool, practical and premium. Deliver one icon, no grid or multiple variants.

## Background prompt

Create a very restrained atmospheric background texture for the graph canvas of a professional Freelancer-inspired space mission editor. Wide 16:9 landscape 1920x1080. Almost black navy #0B111B across the entire image, sparse tiny dim stars and an extremely faint soft blue nebula drifting along the far edges, with a mostly empty dark center. Low contrast, very dark, no bright stars, no sun, planets, ships, grids, text, UI, icons, beams, flares or high-frequency speckle. This image sits behind thin graph edges and small labels: it must never compete with readable information. Subtle cinematic deep space atmosphere, understated enough for hours of coding. A single continuous background.
